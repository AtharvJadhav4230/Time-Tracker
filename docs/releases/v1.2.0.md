# Local Time Tracker v1.2.0

This release integrates 19 contributions from @Ymax27 and strengthens local,
offline tracking and reporting.

## Improvements

- Analytics rankings stay consistent when durations tie, including names and
  browser titles that differ only by case.
- Source users can preview category rules with `preview_category.py`, generate
  a fictional database with `scripts/generate_demo_data.py`, and request the
  tracker version with `python track.py --version`.
- Report CLI database errors produce concise failures, and failed database
  initialization closes its connection.
- The Windows first-run guide, architecture guide and fork-first setup make
  using and contributing to the project easier.
- Regression coverage now includes tracking transitions, category validation,
  UTC/duration storage, interval boundaries, report clipping/escaping,
  analytics sessions/buckets, command entry points and Win32 fallbacks.

## Validation and downloads

The full suite passes on Windows Python 3.11 and 3.13 and Ubuntu Python 3.12.
The installer is built from this release's exact source commit using
`build_release.ps1`, which runs the suite before packaging.

Download `LocalTimeTracker-Setup-1.2.0-x64.exe` and `SHA256SUMS.txt`.
The new preview and synthetic-data commands are source tools documented in the
repository. There is no activity database migration in this release.
